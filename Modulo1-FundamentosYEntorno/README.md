**Monitoría de Algoritmos y Programación — Talento Magdalena y Talento Santa Marta (2026-II)**
Monitor: Carlos Andrés Sehuanes Angulo · Ingeniería de Sistemas

Este módulo es la base de todo el semestre. Antes de escribir la primera línea de código, cada estudiante debe sentirse cómodo con su **entorno de trabajo**: el editor, el formato en que se documenta, la terminal, el control de versiones y la plataforma donde todo eso se comparte con el mundo.

La idea no es memorizar comandos, sino entender **para qué sirve cada herramienta** y **por qué la usan profesionalmente** las empresas de tecnología, las universidades y los proyectos de código abierto más grandes del planeta.

## 🎯 Objetivo del módulo

Al finalizar este módulo (Semana 1, Sesiones 1-3 de la [planeación general](../planecion.md)), el estudiante debe ser capaz de:

1. Instalar y configurar Visual Studio Code con las extensiones adecuadas para su lenguaje.
2. Escribir un documento Markdown legible tanto para humanos como para sistemas automatizados.
3. Moverse por el sistema de archivos y ejecutar programas desde la terminal, sin depender exclusivamente del mouse.
4. Ejecutar el flujo básico de Git (`status`, `add`, `commit`, `push`, `pull`) desde la terminal y reconocer su equivalente en una interfaz gráfica.
5. Crear un repositorio en GitHub, entender su README, y saber qué beneficios institucionales/educativos tiene disponibles como estudiante.
6. Aplicar al menos tres hábitos de "código limpio" recomendados por autores y profesionales reconocidos de la industria.

## 🧭 Cómo usar este módulo (Aula Invertida)

Siguiendo la metodología de [Aula Invertida](../metodologias.md#1-modelo-de-aula-invertida-flipped-classroom) del plan de trabajo:

- **Antes de la sesión:** lee el `README.md` de la subcarpeta correspondiente (10-15 min).
- **Durante la sesión:** practicamos juntos, resolvemos dudas y hacemos los retos prácticos.
- **Después de la sesión:** completa el checklist de autoevaluación al final de cada subcarpeta.

## ✅ Checklist general del módulo

- [ ] Tengo VS Code instalado con las extensiones recomendadas.
- [ ] Puedo crear y dar formato a un archivo `.md`.
- [ ] Sé abrir una terminal y navegar entre carpetas (`cd`, `ls`/`dir`, `pwd`).
- [ ] Ejecuté mi primer `git init`, `git add`, `git commit`.
- [ ] Tengo una cuenta de GitHub activa y activé (o solicité) el GitHub Student Developer Pack.
- [ ] Elegí al menos un libro o autor de la sección de buenas prácticas para consultar durante el semestre.
